# 构建工作台体验重构：实现与验收

以 `main` 的 `c1908e4` 为基线，按顺序移植调查与原型提交 `2ed08a0`、`ee9e5fc`。原型和设计依据见 [体验调查](ux-review.md)；正式面板使用 Paseo 工作区贡献、React Native 和宿主主题。

## 交互与实现

- 宽屏同时显示目标、配置与命令、工具链；compact 通过页签切换这三个区域。顶部主操作和阻塞原因不随内容滚动。字段错误就地显示，扫描提醒和运行失败分别出现在目标区和运行详情。
- 运行区可拖动分隔条调整高度；键盘用 ↑/↓ 微调，Shift 配合方向键可大步调整，Home/End 跳到上下限。运行历史与详情各自滚动。新运行打开输出；手动换记录保留输出或产物页签。
- 当前工作区的成功探测触发一次目标刷新；失败与历史成功不触发刷新。刷新保留草稿和原目标；出错保留上次列表并可重试。「查看新目标」只切换列表视图，不选目标，也不执行命令。
- Gradle 按项目声明的 Wrapper 分发版本和本机 Java 版本提示运行 JVM 的兼容性，将 `java -version` 作为启动检查单独显示。检测到 daemon JVM criteria、JVM 覆盖或版本证据不足时显示「兼容性未确认」。优先推荐满足已知版本范围的本机候选；保留用户已选工具，即使它已失效或不适用。面板不修改项目 JVM 设置。
- 只有当前工作区、项目声明、工具签名和探测上下文匹配时，才提供该任务的探测选项。未编辑的临时配置可带入这些选项；手工编辑或已保存的选项不被覆盖。执行 Gradle 任务前仍要核对预览并显式确认。

## 第二轮：按原型对齐面板（0.2.1）

- 顶栏左侧显示技术栈和当前目标，右侧依次显示阻塞提示和主操作。目标、配置和工具链使用原型的分栏比例与 37px 标题栏，标题垂直居中；compact 的三个区域页签等宽。
- 「目标」「已保存」在同一栏切换，刷新放在目标标题栏。「配置名称」紧接命令选项，与「保存」同一行；附加产物路径默认折叠，折叠不清空内容。面板不再使用原生设置下拉框，同行文本输入框和按钮均高 32px。
- 工具链整张卡片可选择，保留可换行的完整路径。底部「输出」「产物」用下划线标明当前页签，「重试」「停止」用独立的按钮样式。

使用 `agent-browser` 对照原型，检查了 React Native Web 预览的 1400×850 浅色宽屏和 390×740、320×700 深色 compact。实际操作包括：从 CMake 卡片切换候选并检查工具；保存并从「已保存」重新打开配置；展开、折叠产物路径并确认值仍在；切换 Cargo 历史并确认保留产物页签；键盘调高运行区。注入非法选项和运行失败，分别核对字段错误、主操作阻塞提示、运行详情和重试按钮。

本地截图：原型 `/tmp/zeonest-r2-before-8427.png`；宽屏 `/tmp/zeonest-r2-cargo-wide.png`；compact `/tmp/zeonest-r2-compact-dark.png`；窄屏 `/tmp/zeonest-r2-tools-320.png` 和 `/tmp/zeonest-r2-field-error-320.png`。再次通过 `npm run check`（522 通过、3 跳过、0 失败）和 `npm pack --dry-run --ignore-scripts`（11 个打包文件）；主动 LSP 检查 4 个修改文件，无诊断。

## 输出与常用选项（0.2.2）

- 「输出」页签顶部的「命令预览」默认折叠。展开后显示当次运行实际记录的命令、工作目录和准备步骤；长命令在独立区域滚动，不挤走日志。日志默认跟随底部，向上滚动后保持阅读位置，点「回到底部」恢复跟随。切换记录或产物页签时，每条记录保留自己的折叠状态与阅读位置。暂停期间如果旧日志退出服务端缓冲区，仍可阅读当前内容；恢复跟随后使用最新可用日志。
- 「常用选项」与命令输入框等高，使用 Paseo 原生弹窗，按技术栈和探测／构建场景显示选项。可勾选多项并追加到原草稿末尾，应用后焦点回到输入框，取消不改草稿。CMake 不预填原型示例机器上的 `fmt` 路径。

使用 `agent-browser` 对照原型，检查了正式面板源码的 1400×850 浅色宽屏及 390×740、320×700 深色 compact 预览。注入连续日志后，验证了新运行默认折叠并跟随底部、上滚暂停、跨历史和页签恢复位置、手动回到底部，以及失败摘要和截断提示。验证了弹窗取消不写入、勾选多项时按列表顺序追加。隔离目录中通过常用选项插入 Cargo `--release --offline` 后直接构建，退出码为 `0`，产物页显示 `target/release/workbench-demo`；本次工具链报过 `rust-objcopy` 缺少 `libLLVM.dylib` 的警告，运行仍成功。

本地截图：宽屏 `/tmp/zeonest-r4-cargo-wide.png`，compact 暂停状态 `/tmp/zeonest-r4-product-paused-390.png`，窄屏弹窗 `/tmp/zeonest-r4-product-options-320.png` 和失败状态 `/tmp/zeonest-r4-product-error-320.png`。`npm run check` 通过（527 通过、3 跳过、0 失败），`npm pack --dry-run --ignore-scripts` 通过（11 个打包文件），主动 LSP 检查 8 个修改文件，无诊断。
