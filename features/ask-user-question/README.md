# 问答选项回顾

为 Pi 的 `npm:@juicesharp/rpiv-ask-user-question` 增加回答后的选项回顾。在 timeline 展开「问答」折叠块后，每道题会显示问题、agent 给出的全部选项及说明、用户答案，并标注已选项。

## 行为

- 默认折叠，使用贴近 Paseo 工具行的紧凑标题和问答图标。悬停或展开时显示箭头，展开内容沿细分隔线排列，不为每个选项套卡片。已选项用勾号和主题强调色标记。
- 展开后按原顺序显示所有问题和选项，保留推荐标记及完整说明。
- 每个选项的 `preview` 可单独展开，按原文显示，保留 Markdown 标记、代码和换行。未选中的选项也可查看。
- 支持单选、多选和自定义回答。自定义文字即使与选项同名，也不会标成已选项。
- 保留每题补充和整体补充。部分提交会标出未回答的题目；取消和工具返回的错误会显示对应状态。
- 只处理已完成、名称为 `ask_user_question` 的兼容记录。提问中的选择界面、宿主标记为失败或取消的记录仍使用 Paseo 原生展示。

支持两种工具记录：

1. `detail.type = "unknown"`：直接读取其中的原始参数和 `output.details`，同步转换。
2. `detail.type = "plain_text"` 且 `label = "Questions"`：这是 Paseo 0.15.4 内置 rpiv 适配器的实际输出，只有 Q/A 摘要。首次展开时，客户端通过功能自己的 RPC 请求原始数据。服务端从宿主查询该 agent 的 Pi 会话文件，按完整工具调用 ID 配对参数和结果，再核对会话 ID、当前分支和原生摘要。不会从 Q/A 文字猜测选项。

读取失败、原始会话已删除、记录不匹配或超出限制时，折叠块保留原始 Q/A，并提示选项不可用。请求失败后自动重试一次，也可手动点击「重试读取选项」。只读取当前 Pi 会话的有效分支；切换了会话或被 rewind 丢弃的记录不会借用其他分支的数据。

参数和结果格式依据 `@juicesharp/rpiv-ask-user-question@2.13.9`。回归 fixtures 使用合成数据，不包含个人会话文件。

## Paseo 0.15.4 的轮次折叠限制

Paseo 会先将工具记录转换成插件展示，再统计每轮工具调用。0.15.4 的统计不包含插件记录，因此只有问答、没有其他原生工具调用的一轮，无法稳定纳入宿主的轮次折叠；包含 Read 等工具的一轮可能进入折叠。这与问答自身的展开/收起是两层不同的行为。

现有 SDK 没有修改轮次折叠统计的接口。本版本只调整问答展示，保留这一宿主限制，不修改 Paseo，也不伪造工具调用来影响分组。

## 启用与数据访问

新增功能默认关闭。启用 Zeonest 中的「问答选项回顾」后，按壳提示重载整个插件生效；关闭方式相同。没有额外配置项，也不会安装或启用上游 Pi 扩展。

本功能包含客户端 timeline transformer、renderer 和只读服务端 RPC，使用锁定的 `@getpaseo/plugin@0.15.4`：

- 读取路径仅取自宿主返回的 Pi `persistence.nativeHandle`，客户端只能提交 agent ID、调用 ID 和摘要，不能指定文件路径。不扫描其他会话目录。
- 单个会话文件最多读取 32 MiB，恢复的数据最多 1 MiB。读文件时会经过同一会话的其他记录，但只返回目标调用的问题、选项和答案，不返回其他消息。
- 不写文件、不读取凭据、不联系外部服务，也不改写 agent 收到的答案。数据通过现有 Paseo RPC 回到当前宿主的客户端，成功结果短暂缓存于客户端内存。
- 功能未启用或已停止时，RPC 拒绝业务请求。cleanup 移除客户端贡献，并阻止读取中的迟到结果。

`@tanstack/react-query` 仅作为开发依赖提供类型与测试运行环境；客户端运行时使用 Paseo 提供的 external 模块。

## 验证

```sh
node --import tsx --test features/ask-user-question/tests/*.test.*
npm run check
npm pack --dry-run --ignore-scripts
```

回归测试覆盖结构化记录和真实适配器的纯文本摘要格式、全部选项及预览、答案类型、取消与部分提交、会话分支和调用 ID 校验、读取限制、关闭后的 RPC 拒绝、异步恢复、失败回退、折叠状态、工具行的悬停/按压反馈、选中标记、长文案、主题颜色及 compact 间距。

已对用户提供的测试会话进行只读数据验证，能按调用 ID 恢复四个选项。本次样式调整还用实际 renderer 的渲染树生成独立浏览器快照，检查了 1440、390、320 像素宽下的明暗主题、展开、预览、长文案、加载和失败状态，未发现横向溢出。

独立快照使用测试用的原生组件适配，不能代替真实 Paseo 验收。本次未重载已安装插件；真实 Paseo 的宽屏/compact、明暗主题及错误状态仍需检查。宿主验收时还应确认历史重新打开后能恢复选项、回答前仍使用原生交互。
