# Prompt 管理器

在 Paseo 侧边栏管理带动态占位符的 Prompt 模板，并在命令中心通过弹窗选择模板、引导完成占位符配置后复制到剪贴板。

## 功能行为

- **侧边栏「Prompt」**：打开 Prompt 管理器页面，支持新建、搜索、按标签筛选、编辑、保存、删除与快速应用 Prompt 模板；支持一键导入涵盖全部占位符类型的示例模板。宽屏采用左列表右编辑的双栏布局，compact 布局使用列表/编辑切换。
- **命令中心「Prompt：插入 Prompt」**：在任意页面打开引导弹窗，搜索并选择 Prompt 模板后进入配置视图。宽屏采用左右双栏布局（左侧占位符配置、右侧实时结果预览），compact 布局采用上下排布；结果预览中由各占位符展开的片段及可选行左强调条使用与占位符卡片一一匹配的高亮色（自适应明暗主题）。完成后自动复制到剪贴板并提示粘贴到对话框（受限于 Paseo 0.15.4 公开插件 SDK 暂未提供直接写入对话框草稿的接口）。当侧边栏未挂载（例如 compact 布局收起侧边栏）时，会自动跳转到管理器页面并打开同一弹窗。剪贴板写入失败时保留可选中文本供手动复制。
- **命令中心「Prompt：管理模板」**：直接打开侧边栏的 Prompt 管理器页面。

## 占位符语法与类型

- **填空 (`{{名称}}`)**：应用时输入文本（支持配置默认值、输入提示与多行模式），留空时置空。
- **多选 / 单选 (`{{名称}}`)**：应用时从预置选项中选择内容；支持切换多选/单选模式、配置允许自填与多选间隔符。当最终仅选中 1 项（包括单选场景、多选仅选 1 项或仅填写 1 项自定义内容）时自动省略间隔符。
- **勾选 (`{{名称}}`)**：应用时勾选展开为「勾选时展开内容」，未勾选展开为「未勾选时展开内容」。
- **可选行 (`{{?名称}}`)**：将 `{{?名称}}` 放在行首（也支持同行的 `{{?名称}}...{{/?名称}}` 或将 `{{名称}}` 配置为可选行类型），应用时控制该整行是否保留。可选行内可以继续使用其他占位符；当可选行被省略时，仅属于该行的子占位符会自动跳过，且不残留空行。
- **字面量转义**：使用 `\{{` 输出原始 `{{` 而不解析为占位符。

## 数据与权限

- 功能默认关闭。
- Prompt 模板保存在宿主 Paseo 数据目录下的 `zeonest/prompt-manager/prompts.json`（权限目录 `0700`、文件 `0600`，写入采用临时文件原子替换与并发队列串行化，单宿主上限 500 条）。
- 使用基于 `revision` 的乐观并发控制，多客户端同时编辑同一模板时会提示冲突，可选择采用最新版本或以当前编辑内容覆盖。
- 关闭功能后服务端业务 RPC 会拒绝读写，已有模板文件仍保留在宿主上。本功能不会自动发送消息给 Agent，也不访问外部网络。
