# 历史对话展开

功能 ID：`chat-history`。在用户消息正文中识别 `<chat-history-summary>...</chat-history-summary>`，把前序对话放进 Chat history 折叠区，当前正文显示在下方。历史默认折叠，可在功能配置中改为默认展开。

## 启用

需要 Paseo 0.15.4+。在 Zeonest 功能管理中开启「历史对话展开」，保存后重新加载整个插件。功能默认关闭。

折叠区位于包含摘要的那条消息顶部。分叉摘要位于首条消息时，它就出现在这段对话的开头；插件不移动其他消息，也不创建新的历史记录。

## 展示方式

点击 Chat history 展开，按摘要顺序阅读：

- **Meta**：来源 agent、目录及未标注角色的文本。
- **User**：右侧用户消息，正文可选择复制。
- **Assistant**：助手消息，预览和全文均使用 Paseo 原生 Markdown 展示。
- **Actions**：操作名称与摘要，点击单项展开已保留的详情。

默认每次显示 40 条，点击「显示更多历史」继续阅读；超过 1800 字符的单条内容提供「展开全文」。条数和预览长度均可配置，摘要原文始终完整保留。多段摘要分别折叠；嵌套摘要保留为可选择文本。

当前用户正文使用无额外角色标题的右侧气泡。显示时去掉摘要标签外留下的首尾空行，保留正文内部的换行和缩进；提取出的原始正文不作修改。

「查看摘要原文」显示标签内部的完整文本，方便核对角色划分。Paseo 的摘要用行首 `[User]`、`[Assistant]`、`[操作名称]` 区分条目；原对话若使用了同样的行首格式，划分会有歧义，原文视图可用于核对。代码围栏内的角色标记保留为代码内容。

## 显示配置

在 Zeonest 功能管理中打开「历史对话展开」的配置页。配置保存在当前宿主，保存后通过 Paseo 推送生效，无需重载插件；功能关闭时仍可配置。

| 配置 | 字段 | 默认值 | 范围与行为 |
| --- | --- | --- | --- |
| 默认展开历史 | `defaultExpanded` | `false` | 未手动切换的折叠区跟随设置；手动选择会保留到组件卸载 |
| 单条预览长度 | `previewLength` | `1800` | 0–20000 的整数；`0` 表示直接显示全文 |
| 每次显示条数 | `pageSize` | `40` | 10–200 的整数；包含 Meta、消息和操作 |

配置页保留未保存的草稿。其他客户端修改配置后会提示版本变化；保存发生冲突时，先复制需要的修改，再点击「重新读取」，该操作会丢弃当前草稿。「恢复默认」会重置这三项显示配置。

读取失败或配置无效时，对话区提示错误并暂用默认值，仍可查看历史；配置页提供重新读取和无效配置重置入口。

## 识别范围

历史解析与展示由客户端的 Timeline Transformer + React Native Renderer 完成，仅处理 `user_message.text` 中成对的摘要标签：

```text
<chat-history-summary>
Chat history from a previous Paseo agent.
Source agent: Example
Source directory: /workspace/example

[User] 检查配置读取逻辑。
[Read] src/config.ts
[Assistant] 已完成检查。
</chat-history-summary>

继续处理错误提示。
```

没有标签、标签不成对，或标签仅出现在代码示例中的消息，继续使用原生展示。若宿主传给 Transformer 的只有当前正文，而摘要仍在未透传的结构化附件里，本功能不会命中；仅有附件标题 `Chat history` 也无法解析。

命中的用户消息由插件整体重绘，当前正文按可选择的纯文本展示，不复刻该条原生消息的附件胶囊、图片预览和回退菜单。

Paseo 0.15.4 的分叉摘要保留 User、Assistant 和部分操作摘要，操作的完整参数、结果及状态可能已被省略。功能展示已有信息，不补造操作状态；遇到 `[Earlier chat history omitted]` 或 `[Message truncated]` 时会提示来源摘要已省略或截断内容。

## 数据访问与生命周期

历史内容仅在客户端解析和展示，不读取历史文件，不向服务端发送摘要或向 agent 发送内容。Markdown 的链接行为由 Paseo 提供。折叠、分页和全文展开状态保存在当前组件内。

显示配置使用 Paseo 原生 Settings API，通过内置 RPC 读写宿主级配置并同步到客户端；服务端只注册本功能的配置定义。配置不保存历史内容。

关闭功能并重载插件后移除 Transformer 和 Renderer，消息恢复宿主的原生展示；配置入口和已保存的显示偏好仍然保留。

功能测试覆盖正文保留与气泡边界空行、多段与嵌套标签、代码示例避让、未知操作、空内容、CRLF、大摘要、来源截断标记、默认折叠、原文切换、Markdown 预览与全文、可配置分页、实时设置变化、配置范围校验、版本冲突与草稿保留、加载失败及重置恢复、主题 token、compact 布局和注册清理。

真实 Paseo 的验收步骤：

1. 在获准安装、开启并重载插件后，打开正文包含摘要标签的消息，确认历史默认折叠，当前用户气泡没有额外标题或大块空白。
2. 展开历史与操作详情，核对角色、来源、Markdown 和原文内容；确认长助手消息在「展开全文」前后均按 Markdown 展示，测试多段摘要。
3. 在宽屏、compact、明暗主题下检查布局和可访问性，检查空摘要及标签不完整时的回退。
4. 检查只含结构化附件、不含正文标签的消息，确认仍使用原生展示。
5. 在配置页修改默认展开、预览长度和分页条数，确认保存后更新；检查 `0` 预览长度、跨客户端版本冲突、重新读取及恢复默认。
6. 关闭功能并重载，确认原生消息恢复且配置入口仍可用。
