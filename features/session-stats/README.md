# 会话统计

在当前会话的聊天框上提供统计胶囊。胶囊默认显示近 3 秒的输出即时速度；没有速度样本、执行工具或空闲时显示「会话统计」。点击打开原生弹窗，compact 布局由 Paseo 使用底部面板承载。配色跟随宿主主题。

弹窗只显示标题、轮数与步数和所选指标，不叠加内层卡片或大块留白。统计口径和估算范围放在配置页。没有样本的指标默认隐藏，也可选择显示「未采集」；已知的零值正常显示。

## 统计口径

| 指标 | 计算方式 |
| --- | --- |
| 轮数（总数） | 用户消息数，按 `messageId` / `clientMessageId` 去重 |
| 步数（总数） | 工具批次前后连续的模型文本或推理输出段数；没有前置文本的工具批次也计一步。它是事件推导的步数，不是供应商 API 请求数 |
| 模型用时（总数） | 已观察轮次的墙钟时间，扣除工具执行区间的并集和权限等待时间 |
| 工具调用用时（总数） | 每个已观察到 `running` 起点的调用分别累加至结束；并行调用分别计时，合计可以超过会话墙钟时间。轮次结束时结算尚未结束的调用 |
| 首 token 平均用时 | 每个可观测模型段从轮次开始、工具批次结束或权限等待结束，到首个文本或推理片段的时间，再取算术平均 |
| 输出平均速度 | 可测输出段的总估算输出 token ÷ 总解码时长。解码时长为各段首块至末块的时间差，按时间加权，不对各段 TPS 取算术平均 |
| 工具调用次数（总数） | 按 `callId` 去重的调用数，包含失败和取消的调用 |

轮数、步数和工具次数分页回填宿主可访问的完整 canonical 历史，再合并实时事件。历史缺页、分页游标无法继续前进或实时事件缺少去重序号时，会标注“部分”，不把已加载计数当作完整总数。

用时与速度只统计本客户端连接期间、观察到起点的样本，不从历史消息时间戳推测性能。中途加入正在执行的轮次时等待下一个可观测轮次；重连、历史替换和插件重载会清空性能样本并重新回填计数。失败和取消也会结算已观测的用时。

### 输出速度的估算范围

Paseo SDK 0.15.4 没有逐模型请求的精确解码时间和逐块 token 数。本功能采用通用客户端事件观测，不注入 Pi 扩展，也不读取供应商会话文件。

- 中日韩字符按约 1 token/字符，其余 Unicode 字符按约 4 字符/token 估算；文本和推理均计入，工具参数不计入。
- 平均速度包含可测段首块中的 token。只有一个文本块的段缺少可测解码时长，整段不计入速度样本。
- 即时速度以首块为时间基线，统计其后的增量，窗口可选 1、3、5 秒，每 250 毫秒更新。停顿时衰减为零，执行工具或空闲时胶囊显示「会话统计」。
- 用时与速度保留 `≈` 标记。这些数值反映客户端接收到的事件，包含传输和调度影响。

## 开关与配置

功能 ID 为 `session-stats`，默认关闭。在 Zeonest 设置中切换开关后，按宿主流程重载整个插件生效。

进入子功能的「会话统计」配置页，可设置：

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| 轮数与步数 | 显示 | 控制弹窗标题右侧的计数 |
| 五个指标开关 | 全部显示 | 分别控制模型用时、工具用时、平均 TTFT、平均 TPS 和工具次数 |
| 没有样本的指标 | 隐藏 | 可改为显示「未采集」，不添加秒或 tok/s 单位 |
| 即时速度采样窗口 | 3 秒 | 可选 1、3、5 秒；不改变累计值和时间加权平均 TPS |

配置使用 Paseo 原生 host 级设置，ID 为 `session-stats-preferences`，功能关闭时仍可配置。当前宿主的已连接客户端共用配置，保存后约 2 秒内更新胶囊和已打开的弹窗，无需重载。配置页支持保存、草稿恢复默认、重新读取，以及无效文档重置；并发修改冲突时保留草稿，不覆盖新版本。

全部指标关闭时弹窗显示「未选择统计指标」；启用的指标均无样本时显示「等待采集」。配置读取失败时保留上次有效值，首次失败暂用默认值，并显示简短的重试入口。

## 数据访问与资源清理

统计数据仅使用 Paseo 原生客户端 API：订阅活动会话目录、订阅时间线、分页读取 canonical 历史、注册会话级胶囊。显示配置使用原生设置 RPC，每个客户端每 2 秒读取一次，所有胶囊共用结果，不按会话轮询配置。最多观察最近更新的 32 个活动会话，历史读取最多 4 个并发请求，每页 100 条。较早会话更新后可进入观察范围。

不读取会话文件或凭据，不额外连接第三方服务，不持久化统计或对话内容；只有显示配置通过 Paseo 原生设置持久化。历史处理后只保留计数所需的消息/调用标识；实时缓冲只保存结构化计数信号，不保存聊天文本和工具参数。缓冲超过 4,096 条时标记计数不完整。

连接或历史读取失败时保留现有计数并显示错误，清空性能样本，2 秒后重试；弹窗也提供手动重试。会话归档、删除或移出观察范围时移除胶囊。关闭功能或清理时释放目录和时间线订阅、原生胶囊、配置读取与统计刷新定时器、重试定时器，并拒绝迟到结果。

```sh
node --import tsx --test features/session-stats/tests/*.test.ts features/session-stats/tests/*.test.tsx
npm run check
npm pack --dry-run --ignore-scripts
```

行为测试覆盖累计值、时间加权平均、动态窗口、并行工具计时、权限等待、失败与取消、缺失样本、完整历史分页、实时合并去重、历史替换、重连、自动/手动重试、迟到结果和资源清理。原生 UI 测试替身覆盖宽屏/compact、明暗主题、紧凑结构、指标隐藏、缺失值、加载和错误状态。配置测试覆盖 schema、原生注册、保存冲突、草稿保留、默认值、重置、重新读取、多胶囊共享与清理。

真实 Paseo 的宽屏、compact、明暗主题及出错状态仍需宿主验收；测试替身不验证实际排版、触摸和弹窗定位。此实现未安装或启用插件，也未修改 daemon 配置。
