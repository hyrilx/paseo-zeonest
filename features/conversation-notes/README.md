# 会话笔记

- **侧边栏「笔记」**：页面顶部是当前宿主的全局笔记，下方按最近保存时间列出会话笔记。可以按会话名、工作区或摘要搜索；点一行可编辑笔记或打开所属会话。「刷新」会重新读取宿主上已保存的列表。
- **输入框旁「笔记」**：直接打开当前会话的笔记；「笔记 ·」表示已保存内容。宽屏使用锚定浮窗，compact 布局使用底部面板。两处使用同一份笔记和当前客户端的草稿。

列表包含当前宿主目录中可见的会话，包括归档会话。已删除或宿主不再列出的会话不会显示；已有笔记文件仍保留。

## 编辑与保存

- 「编辑」里可以连续输入和跨行选中 Markdown。「预览」显示排版后的笔记。切换模式时窗口高度不变，长笔记在正文区内滚动。点待办方框即可勾选或取消，返回编辑时会看到更新后的标记。
- 编辑工具栏可加粗、加删除线、设置标题、创建无序列表和待办列表。标题与列表作用于当前行或选中的多行。把光标放在待办项内，也可以用「切换勾选状态」直接修改它。
- 编辑后会自动保存，状态显示在面板右上角。关闭面板或切换会话会立即提交待保存的更改。保存失败时，点状态图标可以重试或复制草稿；关闭面板再打开，同一客户端仍能看到草稿。草稿只保留在当前插件客户端内存，不会跨客户端同步，刷新、退出客户端或重载插件前请先保存或复制。
- 同一宿主上的其他客户端重新打开笔记，会读到最新保存的版本。若编辑期间有其他客户端先保存，面板会保留草稿并提示冲突，可复制两版、放弃草稿，或明确用草稿替换宿主版。如果替换前已有更新的版本，仍会提示冲突。

## 偏好设置

在「功能集 → 会话笔记」可设置打开时的视图（默认编辑）、编辑字号（默认标准）和 Markdown 工具栏（默认显示）。隐藏工具栏后仍可直接输入 Markdown。偏好保存在当前宿主，功能关闭时也能配置；保存后下次打开笔记生效。笔记面板里手动切换编辑和预览，不会改变默认视图。

## 数据与权限

功能默认关闭。全局笔记每台宿主一份，会话笔记每场会话一份。Markdown 正文和版本号保存在宿主的 Paseo 数据目录 `zeonest/conversation-notes/`，每份上限为 16,384 个 UTF-16 代码单元。关闭功能会拒绝笔记读写，已有内容仍在宿主。笔记不会写入时间线，也不会发送给 Agent。

## 验证

- `npm run check` 和 `npm pack --dry-run --ignore-scripts`。
- 使用 `@getpaseo/plugin@0.15.4` 的类型检查。自动化测试覆盖全局笔记隔离、目录分页、归档笔记、搜索和来源跳转、两处编辑的草稿共享、Markdown 快捷操作、预览勾选、草稿重试、版本冲突和偏好应用。
- 在模拟宿主中用 RN Web 验证了宽屏亮色下的搜索、笔记详情和摘要更新，以及 compact 暗色下的全局笔记勾选回写、目录读取失败与重试。编辑与预览切换、保存失败重试和模拟中文组合输入也在此环境中验证。
- 未在真实 Paseo 安装或启用。实际侧边栏入口、会话跳转、浮窗和底部面板、明暗主题、系统中文输入法与原生键盘仍待验收。
