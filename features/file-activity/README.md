# 文件活动

在工作区侧边栏的「+」菜单中打开「文件活动」，选择会话后按轮查看 agent 的本地文件工具记录。功能 ID 为 `file-activity`，默认关闭。

## 使用

1. 在 Zeonest 功能管理页开启「文件活动」，按壳的提示整体重载插件。
2. 打开工作区，在侧边栏「+」中选择「文件活动」。
3. 在面板的「会话」下拉框选择当前工作区的会话。只有一个可用会话时自动选择；多个会话时显式选择，不把最近活跃会话当作当前会话。新建会话后可刷新列表。
4. 选择查看范围：
   - **跟随最新轮**：新用户消息到达时，切换到最新轮；该轮的工具状态继续更新。
   - **手动选轮**：通过轮次下拉框、上一轮或下一轮切换。新消息不会改变选择。
   - **全会话**：显示已加载历史中的所有活动，仍受历史记录上限约束。
5. 勾选新增、删除、修改、查询类别，按时间、类别或路径排序，可切换升降序。时间排序采用工具首次出现的时间线序号，类别升序为新增、删除、修改、查询。
6. 展开一项查看正文、diff 或读取范围。「查看第 N 轮的活动」只切换本面板到该轮，不滚动主对话。

也可以在当前会话的 Command Center 中执行「查看当前会话文件活动」，直接打开绑定该会话的侧边栏面板。

侧边栏「+」只列出工作区面板，不列出 `addAgentPanel` 注册的会话面板。0.1.1 增加了工作区入口；由于该入口不传入当前会话 ID，面板提供显式会话选择，直接绑定当前会话则使用上述命令。

每个工作区面板会保存所选会话，并分别保存各会话的范围、轮次、筛选和排序。切换会话会释放旧会话订阅。正文仅在面板内存中处理，不写入面板持久化状态。

## 活动详情与识别范围

| 类别 | 识别依据 | 展示方式 |
| --- | --- | --- |
| 新增 | 明确的 `create_file`，或补丁的 Add File / `/dev/null` 新建记录 | 工具记录中的新增全文；长内容可继续逐批展开 |
| 删除 | 明确的 `delete_file` / `remove_file`，或补丁中的删除记录 | 路径、工具状态；有删除 diff 时显示 diff，否则注明缺少删除前正文 |
| 修改 | 原生 edit、已识别的替换工具与更新补丁 | 优先显示工具 diff；仅有替换前后片段时生成片段 diff，并注明行号相对于片段 |
| 查询 | 原生 read、已识别的读取工具及本地搜索返回的文件路径 | 请求起始行、行数或搜索词，以及工具提供的读取正文；缺少范围时明确提示 |

支持 Paseo 的原生 read / edit / write / search 详情，以及 `unknown` 详情中可识别的 `read` / `read_file`、`edit` / `edit_file`、`write` / `write_file`、`create_file`、`delete_file` / `remove_file`、`apply_patch`。工具命名空间前缀会被去掉，例如 `functions.edit`。

数据有以下边界：

- `write` 记录未说明文件此前是否存在，归入「修改」并展示提交的正文，不能保证还原覆盖前的 diff。
- 只处理工具记录。任意 shell 命令、未识别工具、网页搜索和远程 URL 不会被猜测成本地文件活动。搜索结果只代表工具返回了对应路径，不等同于读完该文件。
- 正文和范围以宿主提供的记录为准。被宿主裁剪、未记录或无法解析的内容不能还原；本功能不读取当前磁盘来补齐历史。
- 进行中、失败、取消的请求会标注状态，默认一起展示；可关闭「显示进行中、失败及取消的请求」，只看已完成记录。请求中的 diff 不代表已经落盘。
- 片段总长度超过 400000 字符，或 diff 计算超过 50ms 时，不在客户端生成片段 diff。已有的工具 diff 仍可查看。

轮次优先采用宿主的 `turnId`，没有时按最近的用户消息分组。没有可归属用户消息的记录放入「未归属轮次」。显示的轮号按已加载历史编排；历史不完整时不视为整段会话的绝对轮号。

### 桌面滚动联动

本版未提供随主对话滚动选轮，也未提供从活动反向定位主对话消息。

已核对仓库锁定的 `@getpaseo/plugin@0.15.4` 类型、Paseo 桌面构建和公开源码：桌面内部有阅读位置与消息定位逻辑，但当前插件 client 契约没有导出相应订阅或定位接口。实现未使用 DOM、私有全局对象或宿主内部模块绕过此限制。「跟随最新轮」跟随新消息，不跟随阅读位置。

## 配置

在 Zeonest 的「文件活动」配置入口中修改，功能关闭时配置页仍可用。配置通过 Paseo 原生 settings 保存，作用域为当前 host。

| 配置 | 默认值 | 可选值 |
| --- | --- | --- |
| 默认查看范围 | 跟随最新轮 | 跟随最新轮、手动选轮、全会话 |
| 默认排序 | 时间 | 时间、类别、路径 |
| 降序 | 关闭 | 开 / 关 |
| 显示进行中、失败及取消的请求 | 开启 | 开 / 关 |
| 历史记录上限 | 5000 条 | 1000、5000、20000 |
| 每次展开的正文行数 | 300 行 | 100、300、1000 |

历史记录上限统计宿主返回的所有时间线条目，包含用户消息与其他条目，不只统计文件活动。达到上限、历史缺页或记录缺少序号时会提示历史不完整。新面板使用默认显示；已有面板保留自身的显示状态。历史上限和正文行数在重新打开面板后应用。

保存使用原始 revision 校验，冲突或失败时保留草稿。「重新读取」丢弃草稿；「使用默认值」只改变草稿，保存后生效。

## 数据访问与清理

- 工作区入口通过当前 host 的 SDK 分页读取会话目录，按工作区过滤；SDK 0.15.4 不支持目录的工作区过滤参数，因此分页完成前不自动推断唯一会话。目录只保留当前工作区的 ID 和显示标签，不订阅其他会话的时间线。
- 只在面板挂载期间订阅所选 host、所选 agent 的时间线，订阅就绪后分页读取历史；断线恢复或时间线替换后重新读取。
- 读取失败时展示错误与重新读取入口。历史缺页不被当作完整结果。
- 关闭面板、切换 agent / host 或停止子功能时释放订阅、取消目录请求并丢弃迟到结果。插件清理会等待已经开始的订阅释放。
- 不注册业务 RPC，不运行服务端业务，不读写工作区文件，不监控文件系统，不上传正文。服务端接入文件只注册原生配置。

## 验证

功能测试位于 `tests/`，覆盖活动解析、工具状态去重、轮次与排序、分页、重连、替换、迟到响应、清理、面板交互及设置冲突处理。入口回归测试按实际宿主的 workspace context 与 explorer location 过滤规则检查「+」菜单，并覆盖当前会话命令、会话选择、各会话状态恢复和目录取消。

已通过 `npm run check`（全库 418 项通过、1 项可选真实 Pi CLI 测试跳过）和打包预检。主动 LSP 检查无错误；测试库及兼容字段有弃用提示，通用 AST 规则有风格建议。

```sh
node --import tsx --test features/file-activity/tests/*.test.*
npm run check
npm pack --dry-run --ignore-scripts
```

原生组件替身测试包含 compact、明暗主题配色和错误状态；尚未在真实 Paseo 中检查宽屏、compact、明暗主题及出错状态。宿主验证需在目标 daemon 上整体重载 Zeonest，无需重启 daemon。
